# PCI Lab — iOS Educational Simulator

Touch-first, offline-capable browser simulation of PCI for a 90% mid-LAD stenosis via right radial access.

> **Education and demonstration only.** Not clinical training, medical advice, or a substitute for supervised instruction.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm test
npm run build
```

## Install on iPhone

After GitHub Pages deploys, open `https://miracle666o.github.io/pci-ios-simulator/` in Safari, tap **Share → Add to Home Screen**, and enable **Open as Web App**. Open once online; the service worker then supports offline use.

## Controls

Use the on-screen touch controls in landscape. The app includes guide, wire, pre-dilation balloon, DES, contrast, fluoroscopy, QCA, physiology, complications, six procedural stages, demo mode, and debrief scoring.
